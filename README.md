# 🌎 Planeta Consciente

Projeto educativo para um Hackathon sobre mudanças climáticas.

## Objetivo
Conscientizar as pessoas sobre as mudanças climáticas e incentivar hábitos sustentáveis.

## Funcionalidades
- Página inicial de apresentação.
- Dicas para economizar água e energia e reduzir resíduos.
- Desafios sustentáveis com lista interativa.
- Curiosidades sobre mudanças climáticas.

## Tecnologias
Python, Flask, HTML e CSS.

## Como executar
1. Instale o Python.
2. Abra esta pasta no VS Code.
3. No terminal, execute:
   ```bash
   python -m venv .venv
   ```
4. Ative o ambiente:
   - Windows: `.venv\\Scripts\\activate`
   - Linux/macOS: `source .venv/bin/activate`
5. Instale o Flask:
   ```bash
   pip install -r requirements.txt
   ```
6. Inicie o site:
   ```bash
   python app.py
   ```
7. Acesse http://127.0.0.1:5000 no navegador.
